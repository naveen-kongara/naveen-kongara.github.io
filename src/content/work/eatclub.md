Own the cloud infrastructure, delivery pipelines and production operations for the engineering team.

- **Platform and Kubernetes:** Run microservices on Docker and Kubernetes (EKS), including scaling and upgrades without downtime. AWS and GCP infrastructure managed as code with CloudFormation and Ansible; production and pre-production environments for new services.
- **CI/CD and releases:** Build and maintain Jenkins and GitLab CI pipelines for backend, frontend, iOS and serverless apps. Canary deployments let teams release often without downtime.
- **Monitoring and on-call:** Built monitoring, logging and tracing with Prometheus, Grafana, Thanos, Tempo, OpenTelemetry, ELK and CloudWatch, and moved off New Relic. Clear alerts and dashboards help spot issues early and fix them faster. Handle 24x7 on-call for production.
- **Databases and data:** Run PostgreSQL, Redis, Elasticsearch and Kafka: tuning, replication, backups and point-in-time recovery.
- **Cloud cost:** Cut the Redshift bill by about 75%, and keep AWS and GCP spend in check through rightsizing, reserved and Graviton instances, storage lifecycle rules, cheaper CDN pricing and removing unused resources, and cost anomaly alerts.
- **Security:** Limit network access to production databases, review IAM access on AWS and GCP, remove stale DNS records, block abusive traffic with WAF, and run vulnerability scans and SAST.
- **Upgrades:** Plan and carry out upgrades with little or no disruption: Rails services to Ruby 3.4 (up to 27% lower p95 latency), Jenkins, ELK, Kafka, Redash, Airflow and the OS on outlet machines.
- **Team:** Help developers launch new services, mentor junior engineers and evaluate new tools.
