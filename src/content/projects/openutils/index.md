![OpenUtils home page](/openutils-home.png)

OpenUtils is a set of small developer tools that run entirely client-side. Text you paste, files you open, and times you convert stay on your device — nothing is sent to a server.

Built as a React + Vite PWA, it includes five tools:

- Text Compare
- JSON Validator
- YAML Validator
- Code Cleaner
- Time Converter

A strict Content-Security-Policy blocks outbound requests, so the privacy guarantee is enforced at the browser level, not just by convention.
